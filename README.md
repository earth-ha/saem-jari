# 샘자리 (v1.9.0)

**이번엔 어디에 앉을까?**

최종 수정: 2026.11.28

게임처럼 즐기는 우리 반 좌석배정 프로그램입니다.

## 사용 방법

1. 학생 수와 교실 배치를 선택합니다. 이름과 성별은 선택 사항입니다.
2. 필요한 학생을 먼저 착석시키고 고정합니다.
3. 랜덤 배정 또는 제비뽑기를 진행합니다.
4. 캐릭터 입장으로 자리를 공개하고, 필요하면 교탁용 좌석표를 인쇄하거나 저장합니다.

## 개인정보

배포본에는 실제 학생 명단을 포함하지 않습니다. 입력한 학급 정보는 브라우저의 로컬 저장소에 저장됩니다. 학생 명단이 포함된 백업 파일은 공개 저장소에 올리지 마세요.

## 실행

웹에서 바로 쓰기: https://earth-ha.github.io/saem-jari/

웹 화면 위쪽의 「HTML 파일 내려받기」로 받아 두면 파일을 두 번 클릭해 열 수 있습니다. index.html을 브라우저에서 열어도 됩니다. 별도 서버나 빌드 과정이 필요하지 않습니다.
